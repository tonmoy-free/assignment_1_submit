# Detailed TypeScript Coding Exercises & Technical Blog Posts
This repository contains comprehensive TypeScript coding exercises and technical blog posts exploring core concepts, optional parameters, union types, tuples, generics, object-oriented programming, and asynchronous workflows.

## Repository Contents & Files
- **`solutions.ts`**: Contains all 8 practical TypeScript problem implementations.
- **[Type Aliases vs Interfaces](./type-vs-interface.md)**: A technical blog post analyzing the core differences, declaration merging, and use cases between `type` and `interface`.
- **[Type Narrowing Guide](./type-narrowing.md)**: A technical blog post exploring how type narrowing works using `typeof`, `instanceof`, and the `in` operator.

## Getting Started
1. You need Node.js and TypeScript installed globally.
2. Run or test the solutions.
